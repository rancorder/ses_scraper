# SES Drive URL Agent (Phase 1)

This layer runs the existing SES screening pipeline without changing scoring logic or profiles.

## CLI

```bash
python agent/run_job.py \
  --drive-url "https://docs.google.com/spreadsheets/d/FILE_ID/edit" \
  --profile t2_lab \
  --output-folder-url "https://drive.google.com/drive/folders/FOLDER_ID"
```

## Requirements

- Existing project virtualenv and Python dependencies
- `rclone` installed on the VPS
- Existing Google Drive remote (default: `gdrive`, configurable in `config/agent.yaml`)
- The authenticated Drive account must be able to read the input resource and write to the output folder

## Phase 1 flow

Drive URL -> rclone download/export -> existing `batch_run.py` -> collect job-specific batch outputs -> existing `merge_results.py` -> rclone upload -> Drive file URL

The Agent gives each downloaded input a unique job-id prefix. This allows it to collect only the batch files generated by that job from the legacy `company_analyzer/output` directory and move them into `work/{job_id}/output` before merging.

The runner also calculates the expected number of batches before execution. If `batch_run.py` exits successfully but one or more batches were not generated, the job fails instead of uploading a partial merged result.
